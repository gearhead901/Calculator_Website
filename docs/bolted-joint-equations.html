1 · Thread and grip geometry

Sizes the bolt: how much area carries the load and how much of the clamped length is threaded.

Tensile-stress area

Tables 8-1, 8-2 · §8-1 · book p. 402–404

At=π4(d−0.9743n)2inch At=π4(d−0.9382p)2metric
  • d major diameter · n threads per inch · p pitch (mm)
  • Ad = πd²/4, the unthreaded shank area

The book lists At in its thread tables; these are the standard formulas those tables come from.

threadAreas()v7 line 2455
function threadAreas(sys, d, p){
  const At = sys === 'inch'
    ? Math.PI/4 * ((d/IN) - 0.9743*(p/IN))**2 * IN*IN
    : Math.PI/4 * (d - 0.9382*p)**2;
  return { At, Ad:Math.PI/4*d*d };
}

Note: the code works in millimetres throughout, so for inch threads it converts to inches, applies the formula, and converts back (IN = 25.4). For inch, p/IN is 1/n.

Grip

Table 8-7, Fig. 8-21 · §8-4 · book p. 418, 440

Bolt and nut: l = every thickness between the head and the nut, washers included.

Cap screw into a tapped part, with h = top member + washer and t₂ = tapped member:

l={h+t2/2t2<dh+d/2t2≥d

Only part of the tapped member is clamped, so only part of it counts.

grip()v7 line 2473
function grip(joint, layers, d){
  if (joint !== 'cap')
    return { l:layers.reduce((s, x) => s + x.t, 0), ... };
  const top = layers.slice(0, -1), tap = layers[layers.length - 1];
  const h = top.reduce((s, x) => s + x.t, 0),
        l = h + (tap.t < d ? tap.t/2 : d/2);
  // the tapped layer is trimmed to the part inside the grip
  return { l, h, inGrip:[...top, { ...tap, t:l - h }] };
}

2 · Stiffness and how the load splits

The bolt and the clamped parts act like springs. Their stiffness ratio decides how much of the outside load the bolt actually feels.

Bolt stiffness

Eq. 8-17 · §8-4 · book p. 419

kb=AdAtEAdlt+Atld

The smooth shank and the threaded part are two springs in series (eq. 8-15, 8-16 combined).

boltStiffness()v7 line 2480
const boltStiffness = (Ad, At, E, l, ld) =>
  Ad*At*E / (Ad*(l - ld) + At*ld);   // l − ld is lt

Stiffness of one cone (frustum)

Eq. 8-19 (8-20 with α = 30°) · §8-5 · book p. 420–421

k=πEdtanαln(2ttanα+D−d)(D+d)(2ttanα+D+d)(D−d)
  • t thickness of this piece · D its small-end diameter · α cone half-angle (30°)
frustum()v7 line 2483
function frustum(E, t, D, d, alphaDeg){
  const ta = Math.tan(alphaDeg*Math.PI/180);
  return Math.PI*E*d*ta / Math.log(
    ((2*t*ta + D - d)*(D + d)) / ((2*t*ta + D + d)*(D - d)));
}

Member stiffness: cones in series

Eq. 8-18 · §8-5 · method of Examples 8-2 and 8-5 · book p. 419, 422–424, 440

1km=1k1+1k2+1k3+⋯

A cone grows from each bearing face to the middle of the grip. Wherever it crosses into a different material it is cut, and the next piece starts wider:

Dpiece=dw+2·depth·tanα,dw≈1.5d

What the code adds: the book does this splitting by hand for each example. The code automates it for any stack of up to four layers.

4 · Static loads and safety factors

What happens when the outside load P is applied, and how far each failure is from happening.

Bolt load and member load

Eq. 8-24, 8-25 · §8-7 · book p. 428

Fb=CP+FiFm=(1−C)P−Fi

Valid only while the parts stay clamped (Fm < 0). P is the load per bolt: Ptotal / N.

solve()v7 lines 2566–2568
const N = Math.max(1, Math.round(inp.N)), P = inp.Pmax/N;
const separated = P*(1 - C) > Fi;
const Fb = separated ? P : C*P + Fi,   // (8-24)
      Fm = (1 - C)*P - Fi;             // (8-25)

Design rule: once the joint separates, the book's formula no longer applies, and the bolt carries the whole load (Fb = P). Any safety factor below 1 counts as a failure, so the exact number past that point doesn't matter: the joint is no longer predicted to survive. The calculator marks every factor below 1 in red.

Fatigue safety factor: Gerber and ASME-elliptic

Eq. 8-43, 8-44 (failure curves) · 8-46, 8-47 (0 → P closed forms) · §8-11 · book p. 439

SaSe+(SmSut)2=1Gerber (SaSe)2+(SmSp)2=1ASME-elliptic

Walk along the load line from (σi, 0) through (σm, σa) until it hits the curve. Then nf = Sa / σa (eq. 8-37).

fatigueFactor()v7 lines 2524–2529

  ? (m, a) => a/Se + (m/Sut)**2         // (8-43)
  : (m, a) => (a/Se)**2 + (m/Sp)**2;    // (8-44)
// point a fraction t of the way along the load line
const at = t => f(si + t*(sm - si), t*sa);
// bisection: find the t where the curve equals 1
let lo = 0, hi = 1; while (at(hi) < 1) hi *= 2;
for (let i = 0; i < 200; i++){
  const m = (lo + hi)/2; if (at(m) < 1) lo = m; else hi = m;
}
return (lo + hi)/2;                      // = Sa / σa = n_f

Different route, same answer: the book gives closed-form results (8-46, 8-47) for a load from 0 to P only. The code solves numerically, so it also handles Pmin > 0. For a 0 → P load it matches 8-46 and 8-47, and Example 8-5's Gerber 3.65 is in the tests.

Not from Shigley. This part is from Machinery's Handbook, 31st ed., book pages 1668–1669. It uses its formula numbers (1)–(6) and inch units: in, psi, lbf.

As=πnLeKn max[12n+0.57735(Es min−Kn max)] An=πnLeDs min[12n+0.57735(Ds min−En max)] Le=2AtπKn max[12+0.57735n(Es min−Kn max)]
  • As external (screw) thread shear area · An internal (nut or hole) thread shear area
  • The four diameters come from the thread class table, in the data file
stripping()v7 lines 2602–2607
const Es = ext.pitch_min, Ds = ext.major_min,
      Kn = int.minor_max, En = int.pitch_max;
// per inch of engagement (multiply by L to get the area)
const aS = Math.PI*n*Kn*(1/(2*n) + 0.57735*(Es - Kn));     // (5)
const aN = Math.PI*n*Ds*(1/(2*n) + 0.57735*(Ds - En));     // (6)
const Le = 2*At / (Math.PI*Kn*(0.5 + 0.57735*n*(Es - Kn))); // (1)

J=As×Sut, screwAn×Sut, nut/holeQ=JLe

J > 1 means the internal thread strips first, so engage Q instead of Le. For screws over 180 ksi, At uses (2b): π(Es min/2 − 0.16238/n)².

What the code adds: the handbook only gives the required engagement. The failure-load comparison is our extension. It takes shear strength as 0.5 × Sut by default, matching the handbook's factor of 2.
