# Reference files

Reference and inspiration material for this project is kept out of git (some files are large and some belong to other teams).

It lives in Dropbox:

- Mac: `~/Library/CloudStorage/Dropbox/Claude/Calculator_Website/Inspiration/`
- Windows: `%USERPROFILE%\Dropbox\Claude\Calculator_Website\Inspiration\`

The repo itself is at `C:\dev\Calculator_Website` on Windows.

Contents:

- `1690_Orbit_shooting_presentation_2024.pptx` — Team 1690 Orbit shooting presentation (2024)
- `1690_Orbit_talk_transcript.txt` — transcript of the Orbit talk
- `4414_software_page_shot_calc.png` — screenshot of Team 4414's shot calculator page
- `4414_tool_suite_overview.png` — overview of Team 4414's tool suite
- `phase4_parking_lot_v1.md` — parking-lot notes for later phases

Engineering references:

- `19.Machinery's handbook.pdf`, `29.Machinerys-Handbook.pdf`, `31.MachinerysHandbook.pdf` — Machinery's Handbook (19th, 29th, 31st editions)
  - Use the 31st edition (2020), the newest. PDF page = book page + 11. Thread stripping and length of engagement are on book pp. 1668–1669, Unified thread limits (Table 3) on book pp. 1951–1974, and ISO metric M-profile limits (Tables 12 and 13) on book pp. 2027–2032. All are already summarized in `docs/thread-stripping-reference.md`, `data/unified_thread_limits.json` and `data/metric_thread_limits.json`.
- `shigley's.pdf` — Shigley's Mechanical Engineering Design, 10th ed. PDF page = book page + 23. Chapter 8 (screws and bolted joints) is PDF pages 424–489. Its bolted-joint method is already summarized in `docs/bolted-joint-reference.md`, so read that first.
- `ASME Y14.5-2009-03.pdf` — ASME Y14.5-2009 dimensioning and tolerancing (GD&T) standard
- `nasa fastner guide.pdf` — NASA fastener design guide
